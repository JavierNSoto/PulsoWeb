# PulsoWeb

Sitio corporativo de PulsoWeb desarrollado con Astro.

## Comandos

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Estructura

- `src/components/layout`: navegación y componentes estructurales.
- `src/components/ui`: piezas visuales reutilizables.
- `src/components/home`: secciones exclusivas de la portada.
- `src/components/services`: plantilla compartida por los servicios.
- `src/data`: navegación, servicios y enlaces globales.
- `src/layouts`: documento HTML y metadatos comunes.
- `src/pages`: rutas públicas generadas por Astro.
- `src/styles`: estilos y tokens globales de marca.

Antes de publicar, configura el número real de WhatsApp en `src/data/site.ts`.
